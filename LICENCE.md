## 🧩 About

**Warface CFG** is a comprehensive configuration and overlay toolkit for Warface featuring a live config editor, in-game GUI overlay, recoil control, FPS optimizer, and custom crosshair. Based on community config tools and popular Windows game utilities.

## ✨ Features

### 🎮 Core Tools
- Config Editor — modify game settings in real-time
- GUI Overlay — on-screen information panel
- Recoil Control — adjust weapon recoil patterns
- Custom Crosshair — personalize aiming reticle
- FPS Optimizer — tweak graphics for performance

### 🎨 Visual & Interface
- Custom HUD — rearrange and resize UI elements
- Color Filters — adjust visual clarity
- FOV Changer — modify field of view
- No Hands — hide weapon model for visibility

- Auto-Config — load optimized presets
- Profile Manager — save and switch configurations
- Keybind Bindings — assign custom hotkeys
- Script Loader — execute config scripts
